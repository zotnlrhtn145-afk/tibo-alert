# 티보 알림

OpenAI 코덱스 책임자 티보(@thsottiaux)의 리셋·리셋권·업그레이드 공지를 한눈에 보는 달력입니다.
브라우저가 [didreset.com](https://didreset.com) 공개 데이터를 직접 받아 오므로 서버 없이 동작하고, 열려 있는 동안 5분마다 새 글을 확인합니다.
폰에서는 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

- `index.html` 페이지 본체 (디자인: 다크 글로우)
- `ko.js` 티보 글 한글 번역과 새 글 자동 번역 규칙
- `manifest.webmanifest`, `sw.js`, `icons/` 설치형 웹앱(PWA) 설정
